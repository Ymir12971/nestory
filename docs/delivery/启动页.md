# Handoff: Nestory — App Splash Screen

## Overview
The splash (launch) screen shown the moment the user taps the Nestory app icon, while the app boots and loads data. It presents the brand mark, wordmark, and slogan on a warm off-white background with a softly breathing green glow halo. It is intentionally calm and minimal — no entrance choreography.

**Live preview:** https://claude.ai/design/p/8f739351-20a5-4180-a26b-82fac4344006?file=Nestory+Splash+Screen.dc.html&via=share

## Screen: Splash / Launch
- **Name:** Splash Screen
- **Purpose:** Brand impression + visual cover while the app initializes. The screen should remain until app data is ready; if loading outlasts the animation, simply hold the resting state (it loops gently — no hard end).
- **Canvas:** Full-screen, portrait. Reference frame 390 × 844 pt (iPhone logical points). Content is centered.
- **Layout:**
  - Root: full-bleed container, `background #FEFCFA`. Flex column, centered both axes, `overflow: hidden`.
  - A centered content stack (logo → wordmark → slogan), nudged slightly above optical center: the stack has `margin-bottom: 64px` so it sits a touch above the vertical middle.
  - Behind the content: a circular radial-gradient glow halo, centered horizontally, vertical center at ~46% of the screen height.

### Components (top → bottom of the center stack)

1. **Logo mark** (`assets/logo.png` — the two-leaf green "V")
   - Size: 90 × 90 pt, `object-fit: contain`.
   - `margin-bottom: 26px`.
   - No animation on the logo itself.
   - Use the app's existing vector/brand asset rather than this PNG if available.

2. **Wordmark** — text "Nestory"
   - Font: **Manrope**, weight **800**.
   - Size: 36px, `letter-spacing: -0.6px`, `line-height: 1`.
   - Color: `#1A1A1A` (neutral-900).
   - `margin-bottom: 11px`.

3. **Slogan** — two lines, broken after "moment":
   ```
   Every little moment
   becomes a story
   ```
   - Font: **Inter**, weight **400**.
   - Size: 14px, `letter-spacing: 0.15px`, `line-height: 1.5`, centered.
   - Color: `#9CA3AF`.
   - `max-width: 260px`.

4. **Glow halo** (behind everything, decorative)
   - 440 × 440 pt circle, centered horizontally, vertical center at 46% of screen height.
   - Fill: `radial-gradient(circle, rgba(35,171,101,A) 0%, transparent 66%)` — green (`#23AB65`) fading to transparent.
   - `pointer-events: none`.

## Interactions & Behavior
- **No tap interactions.** The screen is passive.
- **Single animation — the glow "breathing" loop:**
  - Two properties animate together, driven by one slow sine wave.
  - Period: **2.5s** per full sine cycle (`sin(t · π · 0.8)`, t in seconds → one cycle ≈ 2.5s). Loops indefinitely.
  - **Opacity (alpha A):** oscillates `0.09 ↔ 0.19`, centered at `0.14` (amplitude 0.05).
  - **Scale:** oscillates `0.95 ↔ 1.05`, centered at `1.0` (amplitude 0.05), scaling about the halo's center.
  - Easing: pure sine (ease-in-out feel). No other elements animate.
- **Dismissal:** The host app decides when to transition away (once data is ready). The mock has no built-in exit transition — implement the app's standard splash→home handoff (e.g. a quick cross-fade). If loading outlasts a single cycle, the loop simply continues; there is no terminal frame to wait for.

## State Management
- None on the screen itself. The only external dependency is the app's **boot/ready signal** that triggers dismissal. Use the platform's native launch-screen → first-screen flow.

## Design Tokens (from Nestory Design System)
- **Background:** `#FEFCFA` (neutral-50, warm off-white)
- **Wordmark text:** `#1A1A1A` (neutral-900)
- **Slogan text:** `#9CA3AF`
- **Glow / brand green:** `#23AB65` (primary-500)
- **Typography:**
  - Wordmark — Manrope 800, 36px, letter-spacing −0.6px
  - Slogan — Inter 400, 14px, letter-spacing 0.15px, line-height 1.5
- **Spacing:** logo→wordmark 26px · wordmark→slogan 11px · stack margin-bottom 64px
- **Glow:** 440px circle, alpha 0.09–0.19, scale 0.95–1.05, 2.5s sine loop

## Assets
- **Logo mark** — the Nestory app icon (two-leaf green "V"), provided separately. Prefer the codebase's existing vector brand asset at implementation.
- **Fonts:** **Manrope** (800) and **Inter** (400) — both available on Google Fonts; use the app's bundled copies if already present.
